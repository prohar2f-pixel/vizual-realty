# Changelog — Визуал Realty

## 2026-07-26 — Защищённая админ-панель (подготовлено локально)

### Управление сайтом

- Добавлена закрытая `/admin` с одним серверным логином, scrypt-хешем пароля и зашифрованной AES-256-GCM cookie-сессией.
- Заказчик может искать объекты, выбирать от одного до трёх избранных карточек и менять их порядок.
- Тексты главной, «О нас», команды, контактов, навигации и подвала редактируются через строгий черновик без HTML и Markdown.
- Добавлены закрытый предпросмотр, публикация и один обратимый откат опубликованной версии.
- Карточки сотрудников можно добавлять, упорядочивать, редактировать и скрывать без физического удаления.
- Фотографии сотрудников загружаются с компьютера, проверяются по реальному формату, очищаются от метаданных и сохраняются в WebP вне Git.

### Надёжность и эксплуатация

- Публичные страницы читают только опубликованный контент и используют встроенный резерв при ожидаемой недоступности PostgreSQL.
- Добавлена ранняя baseline-миграция `Agent`/`Property` для чистой установки и строгий preflight/resolve-путь для существующей базы; admin-миграция добавляет `SiteContent` и транзакционно упорядоченные `FeaturedProperty` без удаления данных.
- Seed идемпотентен: повторный запуск не перезаписывает существующий контент и не возвращает намеренно очищенное избранное.
- Добавлены безопасная очистка неиспользуемых фото старше 24 часов и документация backup → migration → seed → build → restart → smoke → rollback.
- Повторяющиеся кнопки избранного и сотрудников получили уникальные доступные имена; сообщения проверки контента полностью локализованы на русский.
- Next.js и ESLint config обновлены до 16.2.12; используемые в runtime Sharp/PostCSS и совместимый `fast-uri` закреплены на исправленных версиях. Production audit не содержит critical/high advisory.

> На живой сайт эта версия не развёртывается без отдельного подтверждения пользователя.
