# Проект: Сайт агентства недвижимости

## Контекст
Потенциальный клиент пришёл по реферралу от **Виталия Антоновича**.
Задача: корпоративный сайт агентства недвижимости с каталогом объектов.
Референс по дизайну/структуре: ndv.ru

## CRM интеграция
Данные предоставила **Арина** (ведёт CRM агентства).

- CRM: **Topnlab** (https://login.topnlab.ru/) — профильная для недвижимости
- API: формат JSON (REST), есть также XML-фид по стандарту Яндекс.Недвижимости
- Данные обновляются в реальном времени (через webhook)
- Доступ к API: нужен API-ключ — выдают сотрудники Topnlab после подключения

## Что нужно получить от агентства
1. `key` — API-ключ (выдают в Topnlab)
2. Настроить `is_feed=true` на нужных объектах в CRM
3. Зарегистрировать наш webhook URL в настройках Topnlab
4. Уточнить у **Виталия** — сколько объектов в каталоге

## Стек для проекта
- Фронтенд: HTML/CSS/JS (статика)
- Бэкенд: Python или Node.js — получает данные из Topnlab, кэширует в БД
- БД: PostgreSQL
- Деплой: Railway

## Файлы в этой папке
- `topnlab-api.md` — конспект API: эндпоинты, параметры, архитектура интеграции
- `api-doc-1.pdf` ... `api-doc-4.pdf` — оригинальная документация Topnlab от Арины
- `doc-large.pdf` — большой PDF (6 МБ), предположительно общая документация
