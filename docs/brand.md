# Фирменный стиль «Визуал»

Источник: логотип от клиента (Виталий), июнь 2026. Стиль по ТЗ: премиум, надёжный, дорогой.

## Палитра (из логотипа)

| Токен | HEX | Где использовать |
|---|---|---|
| `--emerald-900` | `#0A4634` | тёмные секции, футер |
| `--emerald-700` | `#0E5A43` | основной фон бренда, шапка |
| `--emerald-500` | `#157A5C` | ховеры, акценты на тёмном |
| `--gold-500` | `#D4A437` | кнопки, акценты, цена |
| `--gold-300` | `#F0D582` | блики, ховер золота |
| `--gold-700` | `#B07E1E` | золото на светлом фоне (контраст) |
| `--cream` | `#F4F1E9` | текст на тёмном, фон светлых секций |
| `--ink` | `#14241E` | основной текст на светлом |

Контраст: золото на изумруде — для акцентов и кнопок; основной текст — кремовый на изумруде или тёмный на кремовом. Золото мелким текстом на белом плохо читается — для текста на светлом брать `--gold-700`.

## Типографика

- **Заголовки:** благородный шрифт с засечками (как в вордмарке — высокий контраст штрихов). Кандидаты: Playfair Display / Cormorant.
- **Текст:** чистый гротеск для читаемости. Кандидаты: Inter / Manrope.

## Логотип

- Знак: золотой ключ, верх которого — домик с окном. Вордмарк «ВИЗУАЛ», ключ вместо «З».
- Для шапки сайта нужна версия **на прозрачном фоне** (PNG/SVG) — у текущего файла залит изумрудный фон с узором.
- Узор фона (плавные линии) можно вынести отдельной текстурой для секций.

## ⚠️ Опечатка в логотипе

В подписи написано **«агенство»** — правильно **«агентство»** (пропущена буква «т»). На сайте в тексте писать правильно. Стоит сказать Виталию — возможно, захочет поправить и сам логотип.
