# Описание сотрудника в админ-панели

## Цель

Дать заказчику возможность редактировать опыт и достижения каждого сотрудника без изменения кода.

## Данные

В карточку сотрудника добавляется необязательное поле `description` длиной до 1200 символов. Старые карточки без этого поля остаются корректными.

## Админ-панель

В разделе «Команда» рядом с остальными данными сотрудника отображается многострочное поле «Описание / опыт и достижения». Оно сохраняется в черновик и попадает на сайт после обычной публикации.

## Публичный сайт

На странице «Команда» выводится введённый текст. Если описание пустое, абзац не показывается; временная фраза-заглушка удаляется.

## Проверка

Автотесты проверяют сохранение и отображение текста, а также отсутствие заглушки для пустого поля.
