# Автоматическая привязка менеджеров к объектам

## Цель

Каждый опубликованный объект показывает личного менеджера, который выгрузил его в Topnlab. Назначение не редактируется на сайте вручную.

## Источник данных

Во время полной синхронизации и webhook-обновлений сайт получает ID сотрудника из сущности объекта Topnlab. Этот ID сохраняется в связи `Property.agentId → Agent.id`.

Для подготовленных карточек используются постоянные соответствия:

| ID Topnlab | Менеджер |
| --- | --- |
| 296892 | Аянот Елена |
| 296881 | Банитюк Юлия |
| 297093 | Мельник Сергей |
| 298110 | Хаджинова Алина |
| 297092 | Антонович Виталий |

Карточки остальных сотрудников добавляются после получения их ID из Topnlab.

## Отображение

- Каталог: компактный блок с круглым фото и именем личного менеджера.
- Страница объекта: расширенная карточка с фото, именем, телефоном и ссылкой в Telegram.
- Если в CRM объект по ошибке пришёл без ответственного: объект остаётся опубликованным, но не получает чужого менеджера; вместо этого выводится нейтральная ссылка на раздел «Команда».

## Обновления и проверка

Полная синхронизация и webhook используют одинаковую функцию преобразования и сохранения объекта. Проверка включает объект каждого из пяти указанных ID, отсутствие ложного менеджера у объекта без ID и корректное отображение на компьютере и телефоне.
